BitLocker startup PIN: synchronous ServiceUI package

FILES
Install-BitLockerPin.ps1, Uninstall-BitLockerPin.ps1,
Test-BitLockerPinInstalled.ps1, Test-PostProvisioningRequirement.ps1,
PinWindow.xaml, generic-logo.png. Supply reviewed ServiceUI.exe separately.
The public ZIP excludes ServiceUI. ServiceUI is an unsupported Intune workaround.

INTUNE
System install; x64, ARM64, or both; Required pilot assignment; restart suppressed.
Requirement: SYSTEM, 64-bit, Boolean Equals True.
Detection: SYSTEM, 64-bit; protected fully encrypted TPM+PIN with recovery,
no TPM-only bypass. Missing PIN fails detection; an unsuccessful enrollment fails installation.
Install waits for UI; Cancel 1602, failure 1, success 0 after readback.
No scheduled task. Intune retries eligible undetected Required apps; sync does not guarantee immediate retry.

POLICY
Require encryption; suppress third-party encryption warning; allow standard-user encryption.
Additional startup authentication Enabled; without-compatible-TPM False;
TPM Allowed; TPM PIN Allowed; startup key and key+PIN Blocked; minimum6.
Standard-user PIN-change restriction Disabled. Preserve recovery escrow/rotation.
Slate input exception only after verified preboot keyboard test.
Required app detection checks the desired PIN state; this is not an Intune compliance policy.

PREPARATION
OS drive must be fully encrypted and unlocked. Independently confirm recovery access.
Default expects protection On and TPM-only plus recovery protectors.
Optional -InitializeRecoveryOnly permits a fully encrypted recovery-only ProtectionOff
state: TPM ready, successful Entra recovery backup, verified TPM creation, then resume.
Never use that option for intentional maintenance suspension. Existing suspended TPM fails.

DIAGNOSTICS
C:\ProgramData\Microsoft\IntuneManagementExtension\Logs\BitLockerPinEnrollment.log:
stages, sanitized errors and exit codes; rotates at 2 MB.
C:\Program Files\BitLockerPin\LastInstallResult.txt: timestamp, fixed status, exit.
LastPreflightFailure.txt: fixed reference code; compare timestamp for stale records.
PIN and recovery passwords are never logged or passed on command lines.
Uninstall creates/verifies TPM-only before PIN removal; preserves recovery and encryption.
